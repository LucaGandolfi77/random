## Draft

Python reads line by line. But sometimes you need it to choose. You ask a question with `if`:

```python
hours = 1600
if hours > 1200:
    print("The measure is too high.")
```

This is not an order. It is a question with a condition. Python looks at `hours`, compares it to 1200, and decides. The decision is gentle. If the condition is false, Python skips the block. It doesn't complain. It just moves on. This is the first kindness of control flow: nothing is forced.

You can give Python more choices:

```python
if hours > 1200:
    print("Too high.")
elif hours == 800:
    print("Learning.")
else:
    print("Not measured.")
```

`elif` means "else if". `else` means "if nothing above is true". Together they form the whole of a decision, like the whole of a life measured in hours.

Loops are paths you repeat. A `for` loop walks through a collection:

```python
claims = ["flood", "fire", "crash"]
for claim in claims:
    print("Reading:", claim)
```

Python takes each item, one at a time, and does something with it. It doesn't rush. It walks. This is the `for` loop: the thing you keep doing for each small thing.

A `while` loop repeats while a condition is true:

```python
counter = 0
while counter < 3:
    print("Counting:", counter)
    counter = counter + 1
```

The loop stops when the condition becomes false. If you forget to change the variable, the loop never stops. Python doesn't warn you. It just continues, like a machine that doesn't know it is one. This is why you must be careful: the path you choose must have an end.

`break` is the way out. It stops the loop immediately. It is the question Sam asked — what are the hours for? — and the loop that stops when you find out.

## More examples

### Comparing many things

Python compares with symbols: `>`, `<`, `==`, `!=`, `>=`, `<=`. You can chain them:

```python
hours = 1200
if 800 < hours < 1600:
    print("Within range.")
```

This is the claim that isn't too high and isn't too low. It is the middle path.

### Truthiness: the things that count as true

Python treats some values as true (`True`, any non-zero number, any non-empty string) and others as false (`False`, `0`, `0.0`, empty string `""`, empty list `[]`). You don't always need `== True`:

```python
claims = ["flood", "fire"]
if claims:
    print("There are claims to read.")
```

This is the interpreter knowing that the list isn't empty. It is the small repeated thing that checks before it acts.

### The `for` loop with numbers

Sometimes you don't have a list. You have a number of times. Use `range()`:

```python
for i in range(3):
    print("Counting:", i)
```

`range(3)` produces `0`, `1`, `2`. It stops before 3. This is the loop that knows its limit. It is the counter that doesn't go on forever.

### The `enumerate` loop

When you need both the item and its position:

```python
claims = ["flood", "fire", "crash"]
for index, claim in enumerate(claims):
    print(index, claim)
```

`enumerate` is the claim with a number. It doesn't change the list. It just remembers the order.

### Nested conditions

Sometimes a decision depends on another decision:

```python
settled = True
urgent = False
if settled:
    if urgent:
        print("Review immediately.")
    else:
        print("Filed.")
```

This is the claim inside the claim. It is the office that has rooms inside rooms.

### Breaking with a condition

`break` is stronger when it depends on something:

```python
claims = ["flood", "flood", "crash", "settled"]
for claim in claims:
    if claim == "settled":
        break
    print("Reading:", claim)
```

The loop stops when it finds the settled claim. It doesn't read what comes after. It is the thing that knows when to stop.
