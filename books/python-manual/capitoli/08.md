## Draft

No program is an island. Python knows this. It lets you bring other files into your file with `import`:

```python
import math

print(math.sqrt(1600))
```

`math` is a module. It is a file full of functions. You don't have to write `sqrt` yourself. You import it. This is the first thing you share: you don't build everything. You keep what others have built.

You can import only the things you need:

```python
from math import sqrt, pi
```

This is more direct. It is like taking a photo from a desk and putting it on yours. You don't take the whole desk. You take the thing you keep.

Every Python file can be a module and a script at the same time. You check with:

```python
if __name__ == "__main__":
    print("This is the main file.")
```

`__name__` is a variable Python sets. If the file is run directly, it is `"__main__"`. If it is imported, it is the file's name. This is how a module knows whether it is being used or run. It is the office knowing whether it is the floor or the whole building.

Packages are directories. A directory with a file named `__init__.py` is a package. It can contain modules. It is the inner courtyard of many rooms. Python reads the directory like a list of claims, each with its own file.

The standard library is the thing Python already keeps. `os`, `sys`, `json`, `datetime`. These are not external. They are part of the language, like the rules of the office. You don't need to install them. You just import them.

## More examples

### Import with an alias

Sometimes a module has a long name. You can give it a shorter one:

```python
import datetime as dt
now = dt.datetime.now()
```

This is the claim that has a nickname. It is the same claim, but faster to call.

### Importing everything (carefully)

You can import all names from a module, but only if the module allows it:

```python
# In myclaims.py
__all__ = ["Claim", "settle_claim"]
```

Then:

```python
from myclaims import *
```

`__all__` is the list of things the module wants to share. Without it, `import *` takes everything. This is the office that chooses what to show.

### Relative imports

Inside a package, you can import from a neighbor:

```python
# In office/module_a.py
from . import module_b
```

The dot (`.`) means "this package". Two dots (`..`) mean "the parent package". This is the claim that knows its neighbors by name, not by full address.

### Your own module

Create `myclaims.py` in the same folder:

```python
# myclaims.py
def count_unsettled(claims):
    return len([c for c in claims if not c.get("settled", False)])
```

Then in another file:

```python
from myclaims import count_unsettled
print(count_unsettled([{"settled": False}, {"settled": True}]))
```

This is the first claim you wrote that another file can use. It is the small thing you planted that others can water.

### Dynamic import

If you don't know the module's name until the code runs:

```python
import importlib
math_mod = importlib.import_module("math")
print(math_mod.sqrt(16))
```

This is the interpreter that reads the name at the last moment. It is the office that doesn't decide which desk to visit until the meeting starts.
