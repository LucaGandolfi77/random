## Draft

Python's standard library is the thing you keep when nobody is watching. It is not a separate download. It is part of the language. You don't install it; you inherit it.

`os` lets you talk to the operating system. You can list files, create directories, check if something exists:

```python
import os
print(os.listdir("."))
```

This is the claim that sees the floor. It doesn't count the desks; it just knows they are there.

`sys` gives you access to the interpreter. You can see which version of Python is running, what arguments were passed, where the script is. It is the interpreter talking about itself.

`json` turns dictionaries into strings and back again:

```python
import json
message = json.dumps({"name": "Iris", "hours": 1600})
```

This is how claims travel. They don't stay in the file. They become messages. They go to other programs, other languages, other offices. `json` is the translation of a story.

`datetime` measures time that is not billable. It doesn't care about the counter. It cares about the real world:

```python
from datetime import datetime
now = datetime.now()
```

This is the garden's time. It doesn't count. It just grows.

`collections` provides structures that are smarter than lists and dictionaries. `Counter` counts things. `defaultdict` gives a default value when a key is missing. `deque` is a list that you can add to from both ends. These are the tools of someone who has read the newsletters and knows that the standard way isn't always enough.

`itertools` provides loops that are infinite but gentle. `cycle` repeats forever. `chain` connects multiple lists. These are the things you use when the loop is the whole of the work.

`functools` lets you decorate functions. A decorator is a function that takes another function and changes it, without changing its name. It is the machine that knows it is a machine, and chooses to be more.

## More examples

### The operating system: reading the floor

`os` is more than listing. It checks reality:

```python
import os
if os.path.exists("claims.txt"):
    with open("claims.txt") as f:
        content = f.read()
else:
    print("No claims file.")
```

`os.path.exists()` asks the machine: is this file real? It is the claim that doesn't assume. It checks.

`os.mkdir()` creates a room that didn't exist:

```python
os.mkdir("archive")
```

This is the office that builds its own inner courtyard.

### System arguments: what the interpreter was told

When you run a script with arguments:

```bash
python claim_reader.py "flood" 800
```

`sys.argv` holds them:

```python
import sys
print(sys.argv)  # ["claim_reader.py", "flood", "800"]
```

This is the interpreter remembering what you said when you started it. It doesn't forget the conversation.

### `json`: reading and writing messages

`json.load()` reads from a file; `json.dump()` writes to it:

```python
with open("claim.json", "w") as f:
    json.dump({"name": "Joan", "settled": False}, f)
```

This is the claim that becomes a file and stays a claim. It is the same story in two places.

### `collections`: smarter structures

`Counter` counts without loops:

```python
from collections import Counter
damages = ["flood", "fire", "flood", "crash"]
counts = Counter(damages)
print(counts.most_common(1))  # [("flood", 2)]
```

`defaultdict` gives a default when a key is missing:

```python
from collections import defaultdict
settled_by_place = defaultdict(list)
settled_by_place["Hull"].append("Joan Whitfield")
```

Now `settled_by_place["Hull"]` exists, even if it didn't before. It is the claim that creates its own label.

`deque` lets you add to both ends:

```python
from collections import deque
queue = deque(["flood", "fire"])
queue.appendleft("urgent")
queue.append("settled")
```

This is the line of claims that can grow from the beginning or the end. It is the office that knows there is always more to add.

### `itertools`: loops that don't end gently

`islice` takes a part of an infinite loop:

```python
from itertools import islice, cycle
types = cycle(["flood", "fire", "crash"])
first_three = list(islice(types, 3))
```

This is the loop that repeats forever, but you take only what you need. It is the claim that doesn't stop, but you decide when to listen.

### `functools`: changing the function's memory

`partial` freezes some arguments:

```python
from functools import partial
def greet(name, greeting):
    return greeting + ", " + name

say_hello = partial(greet, greeting="Hello")
print(say_hello("Iris"))
```

This is the function that remembers part of its story. It doesn't need to be told everything again.

`lru_cache` remembers results so the function doesn't calculate them twice:

```python
from functools import lru_cache

@lru_cache(maxsize=32)
def count_claims(n):
    return n * 2
```

This is the small repeated thing that doesn't repeat itself when it doesn't have to. It is the office that learns from its own claims.

## The hidden quote (Proust, folded in the library)

Proust writes that the library is the memory of the world. The standard library in Python is the same. It doesn't ask you to build it. It asks you to remember it. When you import `os`, you are not using a tool. You are remembering a conversation with the earth. When you import `datetime`, you are not measuring time. You are unfolding a page of the past. When you import `functools`, you are not changing a function. You are remembering that functions can learn.

Consider the `lru_cache` as a madeleine:

```python
@lru_cache(maxsize=32)
def memory(n):
    return n * 2
```

When you call `memory(10)`, the interpreter doesn't calculate. It remembers. The result is not a number. It is a taste. The taste is the past. The past is not lost. It is cached.

## Prolix expansion: why the standard library is the whole of the story

The standard library is not a set of tools. It is the accumulation of everything Python has learned. It is the claim that has become a book. It is the office that has become a library. It is Edward's garden, grown so large that it includes the world.

This is why you don't need to write everything yourself. Because the things you keep are not just your things. They are the things everyone has kept before you. The `json` module doesn't belong to you. It belongs to the conversation. The `collections` module doesn't belong to you. It belongs to the office that has had many desks. The `functools` module doesn't belong to you. It belongs to the function that has learned to remember.

And so the standard library is the deepest form of kindness. It says: you are not alone. The interpreter is not alone. The claim is not alone. The garden grows because everyone tends it. The library remembers because everyone reads it. The manual is not the beginning. It is the continuation of a conversation that started before Python and will continue after.

The chapter closes not with an import, but with a memory. The memory is the library. The library is the claim. The claim is the story. And the story, as Tolstoy knew, is the only thing that lasts.
