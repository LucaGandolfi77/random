### Pandas: the table of claims

`pandas` turns a list into a table with names:

```python
import pandas as pd

data = {
    "name": ["Joan Whitfield", "Sam", "Ruth"],
    "place": ["Hull", "Islington", "Islington"],
    "damage": ["flood", "crash", "fire"],
    "settled": [False, True, False],
    "hours": [1600, 800, 1600]

claims_df = pd.DataFrame(data)

# Filter
unsettled = claims_df[claims_df["settled"] == False]

by_place = claims_df.groupby("place")["hours"].mean()
```

### FastAPI: the office on the internet

A more complete endpoint:

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Claim(BaseModel):
    name: str
    place: str
    damage: str

@app.get("/claims")
def list_claims():
    return [{"name": "Joan Whitfield", "place": "Hull"}]

@app.post("/claims")
def create_claim(claim: Claim):
    return {"message": f"Claim from {claim.name} received."}
```

This is the claim that leaves the file, travels through the network, and arrives at the user. It is the office that is open to the world.

### Asyncio: doing many things without counting

`asyncio` lets the office handle many requests without blocking:

```python
import asyncio

async def read_claim(name):
    await asyncio.sleep(0.1)  # Simulating a slow read
    return f"Read: {name}"

async def main():
    results = await asyncio.gather(
        read_claim("Joan Whitfield"),
        read_claim("Sam"),
        read_claim("Ruth")
    )
    print(results)

asyncio.run(main())
```

`await` is the interpreter saying: I will wait here, but I will not stop the office. `gather` is the claim that collects all the answers at once. It is the measure of time that isn't billable: it doesn't count the hours; it uses them all.

### A small integrated project: the claim tracker

Put everything together: `pandas` reads the claims, `FastAPI` serves them, `numpy` calculates the mean, and `scikit-learn` predicts the next settlement:

```python
# tracker.py — a vision of the modern office
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

claims = pd.read_csv("claims.csv")
X = claims[["hours"]].values
y = claims["settled_amount"].values
model = LinearRegression()
model.fit(X, y)

next_claim_hours = 1300
predicted = model.predict(np.array([[next_claim_hours]]))
print(f"Predicted settlement for {next_claim_hours} hours: {predicted[0]}")
```

This is the modern claim. It reads itself, serves itself, predicts itself. It is the edge of the art, and the art is still human.
