## Draft

Tolstoy wrote that the greatest events are caused not by great men, but by the accumulation of small actions. The office doesn't work because the manager is great. It works because Ruth counts, Sam asks, Iris reads, and Edward keeps the garden. Python is the same. The language doesn't work because one function is perfect. It works because every module, every import, every variable is doing its small thing, repeatedly, with attention.

The large system is the claim that has become the office, the office that has become the town, the town that has become the world. It is not built in a day. It is built in lines. It is built in the same way Edward kept the garden: not by declaring it finished, but by continuing to tend it.

## The hidden quote (Tolstoy, folded in the package)

In War and Peace, Tolstoy writes that the happiness of a family depends not on the absence of conflict, but on the presence of attention. The package in Python is the same. A package doesn't prevent errors. It organizes them. It gives them rooms. It says: this error belongs here, and this function belongs there, and the import between them is the attention that keeps the peace.

Consider the package `claim_tracker`:

```python
# claim_tracker/__init__.py
from .models import Claim
from .myclaims import count_unsettled
from .data import load_claims
```

This is not a file. It is a treaty. It says: these things belong together. They don't fight. They share. The import is the peace. The module is the garden.

## More examples

### The large import

When you import a package, you are not taking something. You are joining something:

```python
from claim_tracker import Claim, count_unsettled, load_claims
```

This is the claim that knows it is part of a larger story. It doesn't stand alone. It stands with others.

### The module that has many voices

A large module doesn't have one function. It has many voices:

```python
# large_system.py
from models import Claim
from data import DataFrame
from api import FastAPI
from predict import LinearRegression

def office():
    claims = load_claims()
    model = LinearRegression()
    app = FastAPI()
    return {"claims": claims, "model": model, "app": app}
```

This is the office that has departments. It is not one person. It is the accumulation of small attentions.

### The package as garden

The `__init__.py` is not an empty file. It is the gate to the garden:

```python
# claim_tracker/__init__.py
print("The garden is open.")
```

When someone imports the package, the garden speaks. It says: I am here. I am growing. I don't ask for permission.

## Prolix expansion: why Python scales like a garden

A garden doesn't scale because it becomes larger. It scales because it becomes more connected. The claim that grows in one corner connects to the claim in the other corner. The module that serves the claim connects to the module that predicts it. The import is the root that connects them.

This is why Python is the language of large systems. Not because it is fast. Not because it is strict. Because it is kind. The kindness allows the connections. The connections allow the growth. The growth allows the system to become something no one designed alone.

Consider the standard library. It is not a set of rules. It is a garden that others have kept. When you import `json`, you are not using a tool. You are walking through a garden that someone else planted. When you import `os`, you are not talking to the machine. You are talking to the earth, through the language that remembers it.

And so the large system is not solved. It is lived. The claim tracker doesn't solve the claim. It holds it. The interpreter doesn't solve the error. It listens to it. The package doesn't solve the module. It connects it. This is peace. This is the garden. This is the system that outlasts the war of complexity.

The chapter closes not with a function, but with a presence. The presence is the module. The presence is the import. The presence is the claim that knows it belongs to something larger. And the something larger is not the goal. It is the process of growing together.
