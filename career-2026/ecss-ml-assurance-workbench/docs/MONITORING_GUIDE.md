# Monitoring guide (week 5)

Monitoring strategy content lives on each portfolio project (week 3) and is normalized by the
assurance engine into `MON-*` records with categories (Input, Output, Inference, Operational,
Recovery and Update). Thresholds without a defined value are reported as "Threshold Pending
Definition" — never invented.

API: `GET /api/assurance-engine/projects/{id}/monitoring`. UI: Monitoring readiness card on the
week-5 assurance page.
