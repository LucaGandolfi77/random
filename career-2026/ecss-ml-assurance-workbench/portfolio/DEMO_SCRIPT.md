# Demo script

90 s: open /workbench landing -> Start Guided Demo -> skim steps (projects, verdicts, gate, gaps,
package). 3 min: plus one project detail (SEU: FAIL + NO_GO) and gap list. 5 min: plus assurance
page (gate rules + dims) and evidence-package generate+validate.
Key messages: verdicts are explicit; missing data stays visible; recommendation != approval; evidence
is hash-verified.
Do not claim: certification, real missions, production readiness. Expect questions on limitations
(synthetic data, no HIL, no independent V&V).
