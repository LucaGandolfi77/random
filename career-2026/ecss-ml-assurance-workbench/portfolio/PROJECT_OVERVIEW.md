# ML Assurance Workbench — Project overview

Problem: ML components for embedded/space systems need traceable, verifiable assurance evidence.
Solution: an ECSS-informed ML Assurance Workbench integrating Data Readiness Review, ODD definition,
requirements traceability, model documentation, robustness/OOD testing, SEU-oriented fault injection,
FMEA, residual risk, deterministic safety cages, deployment gates, monitoring strategies and versioned
Evidence Packages. Four demonstration projects: Telemetry Anomaly Detector, Onboard Vision
Quantization Lab, SEU Fault Injector, Lunar Landing Safety Cage. Result: a portfolio-ready prototype
with explicit gaps and human decisions. Limits: synthetic data, no certification. Next: independent
V&V studies, hardware-in-the-loop demos, larger evidence base.
