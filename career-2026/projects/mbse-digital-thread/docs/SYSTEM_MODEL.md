# System model (AI Assurance Digital Thread)

JSON model of typed nodes and downstream links: mission -> stakeholder -> system/subsystem/software/
ML requirements -> ODD -> dataset -> model -> test -> evidence -> risk -> deployment -> monitoring,
plus function/component/interface/scenario/state. Stable IDs (prefixes per kind), version/status/
source per node. Demo instance integrates the Lunar Landing ML case (LLS). Full SysML is not
claimed — this is a documented subset with DOT export for diagrams.
