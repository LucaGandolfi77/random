# Evidence acceptance criteria

Document: identified, versioned, linked to baseline, readable, not superseded, required review/approval present. Test report: item/version/objective/environment/config/precondition/procedure/expected vs actual/status/anomaly/date/executor/evidence/tool version. Coverage and static-analysis reports: baseline, tool+version, scope, results, exclusions, residual findings. Review record: artefact, version, reviewer, date, checklist, findings, actions, conclusion. Acceptance is a human decision; criteria only support it.
